# Architecture

## Candidate Approaches

1. 仅改标题：成本最低，不能解决重复与对照结构。
2. 保留原生 Hover，新增本地展示投影与 renderer：推荐研究方向。
3. 独立中文阅读侧栏：可以完全控制阅读排版，交互与生命周期明显扩大，留后续。

## Recommended Design

采用方案 2。完整规则、文件图、数据流、测试和回退见 ../../docs/hover-display-design.md。

- 粗体区块标题、源章节映射 H4–H6、保留段落/列表/示例。
- 对照采用中文在前、原文在后；表格完整配对；部分状态按节点识别。
- 保留来源边界，安全 AST 本地投影，只省略高置信独立签名。
- 展示设置保持服务 revision 与缓存；进行中旧快照，下次 Hover 新模式。模型/密钥/同意等仍按原流程失效。
- 不新增命令链接、HTML、摘要、侧栏或云端请求协议。
- 现有配置枚举与命令 ID 保持，无迁移；可回退到既有 VSIX。
- 两个独立架构角色完成：内容结构与保真、配置交互与兼容。生产实施与代码审查未开展。
